🧵 StitchVerse

A modern tailoring and custom fashion platform where customers connect with professional tailors, explore designs, place custom orders, and track progress — all in one streamlined system.

⭐ Features

Customer & Tailor authentication

Browse, upload, and manage fashion designs

Custom stitching requests with measurement support

Order tracking (Processing → Stitching → Completed → Delivered)

Tailor dashboards for order management

Reviews & feedback system

Admin panel for managing users, orders, and reports

Responsive UI with a modern, clean design

🛠️ Tech Stack

PHP (Core backend)

MySQL (Database)

HTML, CSS, JavaScript

TailwindCSS for modern UI styling
